# ТЗ: Image Studio — текстуры по развёртке модели и чертежи для моделирования

> [!NOTE]
> Всё ниже проверено руками 27.10.2026 на двух моделях (стопка стилизованных глыб, огненная швабра) через Image Studio (Muse, режим `roblox decal` с картинками-референсами) и живой Blender 5.2 через MCP. Картинки экспериментов: `/Users/vechkasov/Documents/Мои проекты/Roblox/lava-arena/.bb/chats/thr_vgdyg342s5/artifacts/tex-by-uv/`. Скрипт подготовки болванок: `Roblox/lava-arena/scripts/tex_guide.py`.

## 1. Зачем

Агенты делают 3D-модели в Blender (через MCP), но текстуры получаются процедурные и однообразные. Нужно, чтобы агент мог по готовой модели получить **рисованную текстуру, которая точно ложится на развёртку**, а для моделирования — **чертёж модели с нескольких сторон** как подложку.

## 2. Что доказано экспериментом

| Приём | Результат | Вывод |
|---|---|---|
| Болванка развёртки (UV-атлас, в который запечены свет и тени формы и плоские цвета частей) → Muse «перерисуй каждый кусок на месте» | Muse сохраняет положение и контур кусков, текстура ложится на модель | **Работает.** Основа режима |
| Контуры кусков, нарисованные на болванке | Muse превращает их в цветные рамки → мультяшные швы на модели | На болванке **без линий**; в промпте «no outlines, no frames» |
| Мелкие куски развёртки (каждая фаска отдельно) | рамки и швы | Крупные куски: Smart UV с углом ~66–72°, отступ 0.03–0.04, запекание с margin 16–24 px |
| Плоские цвета частей в болванке (дерево / ткань / металл / тряпки) | Muse правильно понимает, что где рисовать | Болванка = **цвет части × свет**. Без исходной текстуры — запечь цвета материалов/ID частей |
| Второй референс — концепт предмета | детали в стиле концепта (волокна дерева, царапины, болты) | Передавать концепт вторым изображением |
| Эффекты по месту на модели (подпалины на концах, мох сверху) | Muse всегда считает «низом» куска низ картинки; карту высоты вторым референсом **игнорирует** | **Развернуть куски развёртки: верх модели = верх картинки** (`bpy.ops.uv.align_rotation(method="GEOMETRY", axis="Z")` + `pack_islands(rotate=False)`). После этого подпалины легли точно на концы тряпок |
| Перерисовка ракурсов модели и проекция обратно | Muse меняет силуэт и масштаб → не ложится | **Не использовать** как есть. Возможно, с жёстким референсом контура/глубины — отдельный эксперимент |
| Чертёж «спереди / сбоку / сзади, серая глина + сетка» по концепту | Ровно стоящие виды одной высоты на общей линии, разбивка на части, петли рёбер | **Полезно как подложка для моделирования** (силуэты, пропорции, сечения). Сетка декоративная — топологию из неё не восстановить |

## 3. Что сделать в Image Studio

### 3.1 Новый режим `texture-uv` (раздел «Текстура по модели»)

**Вход:** путь к модели (FBX/GLB/.blend + имя объекта) или готовые болванки; описание стиля; до 2 картинок-референсов (концепт предмета, лист стиля); размер 1024/2048.

**Шаги (плагин сам, через Blender в фоне `--factory-startup -b` или через MCP, если открыт):**
1. Импорт, проверка нормалей.
2. Развёртка, если нет пригодной: Smart UV 66–72°, отступ 0.03–0.04; затем **align_rotation по Z** и `pack_islands(rotate=False)` — куски стоят «верхом вверх».
3. Болванка `guide.png`: запечь COMBINED (свет сверху-слева + мягкий фон) с цветами частей. Нет текстуры — материалы получают плоские различимые цвета, их список «цвет → часть» уходит в промпт.
4. Маска `mask.png` (белое — где есть куски).
5. Генерация Muse: изображения = [guide, концепт?, стиль?]; промпт из шаблона (ниже) + описание частей и стиля. 2–4 варианта.
6. Постобработка: обрезать по маске, раздуть края на 8–16 px (dilate), чтобы не было щелей на швах.
7. Натяжка и предпросмотр: материал с картинкой по той же UV, рендер 2 ракурсов (Cycles/EEVEE), склейка «до / после».
8. Выход: `color.png`, `mask.png`, `guide.png`, `preview.png`, `manifest.json` (модель, объект, имя UV-слоя, размер, промпт), .blend с назначенным материалом. По желанию — `normal.png` из цвета (как в `texture` режиме).

**Шаблон промпта (проверен):**
> Texture atlas for a 3D game model. Image 1 is the UV layout: every shape is one piece of the model surface, its flat color tells the material ({список цвет = часть}); the top of each shape is the top of the model. Repaint EVERY shape in place with {стиль}{, in the look of image 2}. {Эффекты по месту: «… only at the BOTTOM end of …»}. Keep every shape exactly where it is with the same outline, size and base color; no outlines or frames; black background stays black; no text.

### 3.2 Режим `blueprint` (чертёж для моделирования)

**Вход:** концепт предмета/персонажа, список видов (front, side, back, top), стиль подложки (`clay+wire` или `clean line`).
**Выход:** листы видов одной высоты на общей линии + **нарезка по видам** (`front.png`, `side.png`, …) с одинаковым масштабом, прозрачным фоном и `views.json` (рамки видов, базовая линия, высота в px) — чтобы агент сразу поставил их референсами в Blender (Empty Image, ортокамеры) или скормил силуэтному «вырезанию» (`model_from_picture.py`).
Промпт проверен: «Technical modeling blueprint … three orthographic views side by side … same scale, same height, aligned on one horizontal baseline … flat grey clay with a visible black quad wireframe … No perspective, no shadows …».

### 3.3 Скилл для агентов

Раздел в скилле `image-studio` (или отдельный `image-studio-3d-textures`): когда брать `texture-uv`, `texture` (бесшовные), `blueprint`; правила из таблицы раздела 2 (без линий на болванке, крупные куски, верх вверх, цвета частей, концепт вторым референсом, ракурсы не проецировать); как натянуть результат в Blender (UV Map node по имени слоя из manifest) и как запечь под Roblox (SurfaceAppearance: Color/Normal/Roughness). Пример вызова MCP-инструмента и чек-лист приёмки: рендер «до/после» с двух сторон, нет рамок по швам, эффекты на своих местах.

## 4. Приёмка

- Огненная швабра (`Roblox/lava-arena/assets/3d/fire-mop.fbx`) и стопка глыб (`scripts/tex_guide.py -- guide test`) проходят режим `texture-uv` одним вызовом: на предпросмотре нет рамок по швам, подпалины на концах тряпок, детали по частям верные.
- Чертёж огненной швабры (`assets/concept/weapons/fire-mop.png`) нарезан на 3 вида одной высоты, `views.json` корректен.
- Скилл описывает оба режима с примерами; агент без контекста этого чата может по нему затекстурить новую модель.

## 5. Идеи для следующих экспериментов (не обязательны сейчас)

- Карта глубины по концепту (Depth Anything на нашем gpu3d) → рельеф/смещение для барельефов и как подсказка объёма при моделировании по чертежу.
- Перерисовка ракурсов с жёстким контролем (контур + глубина как референс) — если Muse начнёт держать форму, это даст бесшовные текстуры без зависимости от развёртки.
- Карта нормалей и шероховатости из рисованного цвета (как в `texture`) для SurfaceAppearance.
