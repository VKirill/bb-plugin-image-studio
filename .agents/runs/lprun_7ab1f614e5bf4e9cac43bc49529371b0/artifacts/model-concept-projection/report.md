# texture-uv: concept projected onto the model before Muse (TZ 3.4) and the structured Muse prompt (roles, Task, Must not change, bans)

The requester updated the TZ (read tz.md sections 3.1 and 3.4). (A) Concept projection, mandatory for faces, eyes, lettering and patterns: when texture-uv gets a concept (images[0]) and projectConcept is not false, the server cuts the concept to the object in pure TS (key the plain background from the corners, crop to the object's alpha box, fill the background around it with the object's main colour, e.g. the median of object pixels) into <run>/concept_proj.png, and Blender prepare gets `--concept <png> [--concept-view front|back|left|right]` (default front). Blender projects it planar onto the model from that view: object-bbox-normalised coordinates (Generated texture coordinates or equivalent) mapped to the image, e.g. front = (x, z), back = (1-x, z), left/right from y; faces turned away from the view (normal · view direction <= 0, with a short soft blend) keep their part colour or existing texture, so the back is not a mirrored front. The projection replaces the base colour of the facing faces and is baked into guide.png together with the light (COMBINED, same light as now) on ImageStudioUV. prepare.json gets {concept: true, conceptView}.
