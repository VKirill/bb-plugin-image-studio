# Студия картинок для BB

Генерация фотографий текущего проекта BB через [fal.ai](https://fal.ai/) и [kie.ai](https://kie.ai/) (Nano Banana 2, Nano Banana Pro, Muse Image), галерея готовых кадров и профили людей с эталонными снимками.

[English](README.md) · [Релизы](https://github.com/VKirill/bb-plugin-image-studio/releases)

## Как это устроено

- **Галерея** — готовые картинки этого проекта в реальных пропорциях кадра. Нажатие открывает просмотр. Новые файлы пишутся как WebP.
- **Генерация в панели** — промпт, профиль человека, модель, шлюз и размер Nano Banana (по умолчанию **2K**). Соотношение сторон в панели не выбирается: его задаёт модель, подпись кадра видна на превью.
- **Генерация в чате** — попросите фото. Агент открывает форму с прошлой моделью, кадром и размером. Меняете при необходимости и нажимаете «Отправить». Нужен инструмент `image_studio_generate`, не CLI.
- **Профили** — имя, тело, до трёх селфи, при необходимости фото маникюра. Профили общие, готовые картинки — у проекта.
- **Настройки** — галочки моделей, язык EN/RU, ключи API. Введённый ключ главнее Env Catalog. **Muse Image только на fal.ai.**

На телефоне вкладки внизу, чтобы поле промпта не сжималось.

## Установка

```sh
bb plugin install https://github.com/VKirill/bb-plugin-image-studio.git --yes
```

Дальше: боковая панель **Image Studio** → настройки (модели и ключ) → при желании профиль → генерация внизу галереи или просьба в чате проекта.

## Требования

BB 0.43+, аккаунт fal.ai и/или kie.ai (оплата у провайдера). Env Catalog не обязателен.
